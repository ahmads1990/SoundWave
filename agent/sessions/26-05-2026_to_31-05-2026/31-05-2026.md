## Log Timeline

### [15:00:00] - Integration Testing & Generic Repository Refactor
- Removed per-entity repository classes and interfaces (`IUserRepository`, `IRefreshTokenRepository`, `UserRepository`, `RefreshTokenRepository`) in favor of a consolidated generic repository pattern (`IIdentityRepository<>`).

- Replaced the in-memory database configuration for testing with a real PostgreSQL test database container setup.
- Created `IdentityIntegrationTestBase` to manage transaction rollbacks for clean database state between test runs.

### [16:00:00] - Refactoring Token and OTP Services
- Created `ITokenService` and `TokenService` to encapsulate token operations (generating combined user tokens, verifying token hash, reading claims from expired token).
- Created `IOtpService` and `OtpService` to isolate OTP generation logic.
- Registered new services in Dependency Injection inside `IdentityDependencyInjection.cs` and deleted deprecated `ITokenHelper` / `TokenHelper`.
- Refactored `LoginCommandHandler`, `RegisterCommandHandler`, `RefreshTokensCommandHandler`, and `ResendVerificationEmailCommandHandler` to consume the new decoupled services.
- Extracted database calls and domain validations inside handler classes into private helper methods nested within `#region Private Methods`.
- Renamed `VerifyRefreshToken` to `VerifyToken` globally.

### [16:25:00] - Tests and Code Quality
- Updated all handler tests to mock `ITokenService` and `IOtpService`.
- Added pure unit tests for both `TokenService` and `OtpService` verifying signature, token generation, cryptographic validation, and OTP formatting.
- Fixed mismatched XML parameter comments in handler classes, achieving a warning-free clean build.
- Moved `ITokenService.cs` and `IOtpService.cs` from `Services/` to a dedicated `Services/Interfaces/` subfolder.
- Verified test suites: 100% success with 34 tests passing in `SoundWave.Identity.Tests`.

### [18:00:00] - Refresh Token Upsert Support
- Fixed `SaveRefreshTokenAsync` in `TokenService` to support upserting refresh tokens, ensuring we correctly update existing ones when needed.

### [18:15:00] - Logout Feature
- Implemented the `Logout` feature by introducing `LogoutCommand`, `LogoutCommandHandler`, and `LogoutCommandEndpoint`.
- Revokes refresh tokens in the database and adds the JWT identifier (`jti`) to a Redis-backed blacklist to invalidate active access tokens.
- Added corresponding integration tests in `LogoutTests.cs`.

### [18:25:00] - Token Blacklist Middleware
- Added `TokenBlacklistMiddleware` to intercept API requests.
- Validates the incoming JWT `jti` claim against the Redis blacklist, returning a `401 Unauthorized` if a blacklisted token is detected.
- Registered the middleware in the main application pipeline inside `Program.cs`.
